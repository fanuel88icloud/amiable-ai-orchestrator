# Agent Hub Pro

Sto creando una piattaforma chiamata FMS AI Platform che dovrà gestire agenti AI per telefono, WhatsApp, email e documenti.

Per il momento non sviluppare alcun agente.

Crea solo le fondamenta del progetto.

Voglio un’interfaccia moderna e professionale con autenticazione utenti.

La dashboard iniziale deve avere queste sezioni:

Dashboard

Agenti AI

Canali

Tool

Workflow

Log

Impostazioni

Per ora crea solo la struttura delle pagine, senza logica di business.

Utilizza Supabase come backend e organizza il progetto in modo modulare e facilmente estendibile.
